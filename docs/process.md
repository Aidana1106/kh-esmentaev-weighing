# Рабочий процесс команды 

## Доска (GitHub Projects)

| Столбец | Что в нём | WIP-лимит |
|---|---|---|
| Бэклог | Задачи, ещё не подготовленные к работе | — |
| Готово к работе | Прошли DoR, по приоритету | 6 |
| В работе | Делает исполнитель, есть ветка | 6 (по 2 на человека) |
| Ждёт ревью | Открыт PR, CI зелёный | 3 на команду вместе с «Ревью и тест» |
| Ревью и тест | Ревью кода и ручная проверка | — |
| Ждёт заказчика | Нужен ответ/данные заказчика | — (возраст > 3 дней → эскалация) |
| Готово | DoD выполнен, PR влит | — |
| Срочные (полоса) | Дефект, мешающий работе или демо | 1 |

Упёрлись в лимит — новую задачу не берём, помогаем закрыть начатое.

## Политики перехода

- **Бэклог → Готово к работе:** выполнен DoR.
- **Готово к работе → В работе:** есть место по лимиту; один исполнитель; ветка по CONTRIBUTING.md.
- **В работе → Ждёт ревью:** PR со ссылкой на задачу, CI прошёл, автор сам проверил сценарий.
- **Ждёт ревью → Ревью и тест:** ревьюер — не автор; ревью не позже следующего рабочего дня.
- **Ревью и тест → Готово:** выполнен DoD, PR влит в main.
- **→ Ждёт заказчика:** записан конкретный вопрос и дата, когда он задан.

## Классы обслуживания

| Класс | Примеры | Политика | Срок |
|---|---|---|---|
| Срочный | Ошибка в нетто, не открывается форма | Вне очереди, лимит 1 | 1 день |
| Фиксированная дата | Тара от заказчика, план перехода, приёмка | От даты назад | К дате |
| Стандартный | Задачи спринта | По приоритету | p85 ≤ 5 дней (уточнить по данным) |
| Незначительный | Тексты, техдолг | При свободном месте | — |

## Definition of Ready

- понятна ценность и роль пользователя;
- есть критерии приёмки, включая негативный сценарий;
- указаны применимые НФТ;
- внешние зависимости выявлены и данные получены;
- задача ≤ 3 дней работы одного человека, иначе режем;
- указан компонент ([Весы] / [Интерфейс] / [Документация]) и класс обслуживания.

## Definition of Done

- код в main через PR, ревью сделал другой участник;
- CI зелёный (pytest);
- для интерфейса пройден `scripts/e2e_smoke.py`;
- проверены затронутые НФТ: офлайн, клавиатура, RU/KZ тексты;
- обновлены README / ADR / инструкция, если поведение изменилось;
- развёрнуто на тестовом сервере, открывается с телефона;
- задача закрыта на доске со ссылкой на PR.

## Метрики

Поля дат в проекте: «Готова к работе», «Взята в работу», «На ревью», «Готово» — ставятся при переносе карточки. После спринта: Export view data → лист «Задачи» шаблона метрик.
